## What this repository solves

Anyone building a calendar app, doing cultural research or processing Vietnamese text soon needs a
table of can chi (the sexagenary stem-branch cycle), a lunisolar calendar or a list of festivals they
can trust. Such tables are easy to find on the web, but most are copied by hand, carry no licence, do
not say which convention they follow, and disagree with each other exactly where it gets hard.

This repository holds **33 datasets, 168,253 rows** of calendrical, can chi, tiết khí (solar term),
I Ching (Kinh Dịch) and festival data in machine-readable form (CSV, JSON, plus a `.meta.json` description). All of
it is generated by the same engine that runs the tools on [nhatnguyet.org](https://nhatnguyet.org), so the numbers in
the files and the numbers on the site are one and the same.

Two things set it apart from an ordinary lookup table:

- **Computed facts are kept apart from traditional convention.** Every dataset states its provenance: 10 transcribed from sources, 10 editorial, 9 derived from rules, 4 computed.
  Every row has a `nguon` column saying whether the value was computed, copied from a named book, or edited.
- **Where the schools disagree is said out loud.** The `ghi_chu` column records variant readings per row;
  [`docs/bat-dong.md`](docs/bat-dong.md) records each dataset's choices and why; the `diem-bat-dong-giua-cac-phai` dataset collects those points as data.

The datasets `loai-le-cung-viet-nam`, `van-cung-viet-nam`, `nghi-thuc-cung-viet-nam`, `le-vat-cung-viet-nam`,
`kieng-ky-luu-y-le-cung` and `hoi-dap-le-cung` are different: they hold offering prayers and rites collected from
Vietnamese-language pages, not computed values; they describe custom according to the sources, prescribe nothing, and
practice differs from place to place. These prayers belong to folk belief and custom; the wording is kept in Vietnamese as the source gives it. The `neu_nguon` column tells which rows
give the name and address of the source page and which are collected texts whose source page the dataset does not
name; those texts were not written by Nhật Nguyệt.

## Quick start

The two examples in [`examples/`](examples) run as they are, with no library to install:

```bash
# Python: look up the can chi and nạp âm of a year in the 60 Hoa Giáp dataset
cd examples/python && python3 doc-du-lieu.py

# JavaScript: read the twelve earthly branches with an RFC 4180 CSV reader
cd examples/javascript && node doc-du-lieu.js
```

To read a single file without cloning:

```
https://raw.githubusercontent.com/Nhat-Nguyet/du-lieu-am-lich/main/data/<slug>.csv
```

## Conventions and limitations

- [`docs/quy-uoc.md`](docs/quy-uoc.md): CSV format, the three required columns, provenance columns, the three kinds of version, determinism.
- [`docs/bat-dong.md`](docs/bat-dong.md): where the schools disagree and what each dataset chose. The most useful file here.
- [`docs/mo-hinh.md`](docs/mo-hinh.md): profiles of the computation models (ephemeris, time zone, rounding, reference sources).
- [`docs/nguon-thu-tich.md`](docs/nguon-thu-tich.md): the source texts behind each dataset, and which rest on no book at all.
- [`docs/oracle.md`](docs/oracle.md): `data/oracle.csv`, the public cross-check set between the data and the tools.
- `data/nguon-thu-tich.csv`: the source register, one `source_id` per source (work, author, edition, juan, URL, access date, hash of the reference file); each dataset's metadata points to `source_ids`.
- `data/quy-tac.json`: the rule register, one `rule_id` per rule (computation rule or convention, version, content hash); each dataset's metadata points to `rule_ids`.
- `data/changelog.json`: every version of every dataset (rows added, removed, changed where measured) and the impact report of each release.

The files in `docs/` are written in Vietnamese with English summaries.

This is data about cultural and calendrical conventions, not scientific claims:

> This dataset records cultural and calendrical conventions, not scientific claims. It is suitable for cultural research, NLP, and calendar applications. It is not intended for predicting events, evaluating people, or making decisions that affect anyone.
