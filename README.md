*Vietnamese calendrical and cultural reference data*

## 1. Đây là gì · What this is

27 bộ dữ liệu tra cứu lịch pháp và văn hoá Việt Nam, tổng cộng
**166,722 dòng**, phát hành theo **CC BY 4.0**:
dùng lại được cho cả mục đích thương mại, sửa đổi được, chỉ cần ghi nguồn.

Dữ liệu lịch pháp và can chi tiếng Việt ở dạng máy đọc, có giấy phép rõ ràng,
gần như không tồn tại. Đây là chỗ trống mà kho này lấp.

*27 reference datasets on Vietnamese calendrical systems and
culture, 166,722 rows in total, released under
CC BY 4.0. Machine-readable Vietnamese calendrical data with a clear licence
barely exists; this fills that gap.*

Mỗi bộ có ba tệp trong `data/`: `.csv`, `.json` và `.meta.json`.
Tệp `.meta.json` mô tả từng cột, nêu quy ước đã chọn và ghi giới hạn sử
dụng, nên đọc được **mà không cần tải dữ liệu về trước**.

## 3. Dùng thế nào · How to use

### Python

```bash
cd examples/python && python3 doc-du-lieu.py
```

### JavaScript

```bash
cd examples/javascript && node doc-du-lieu.js
```

Cả hai ví dụ chạy được ngay, không cần cài thư viện nào.

## 7. Giới hạn sử dụng · Limitations

> Bộ dữ liệu này ghi lại quy ước văn hoá và lịch pháp, không phải phát biểu khoa học. Nó dùng được cho nghiên cứu văn hoá, xử lý ngôn ngữ và ứng dụng lịch. Nó không dùng để dự đoán sự kiện, đánh giá con người, hay ra quyết định ảnh hưởng tới ai.
>
> *This dataset records cultural and calendrical conventions, not scientific claims. It is suitable for cultural research, NLP, and calendar applications. It is not intended for predicting events, evaluating people, or making decisions that affect anyone.*

## Đóng góp · Contributing

Kho này **đồng bộ một chiều** từ https://nhatnguyet.org. Pull request sửa tệp trong
`data/` sẽ bị ghi đè ở lượt đồng bộ sau, nên xin đừng mất công.

Thấy số sai thì **mở issue**. Dữ liệu được sửa ở đầu nguồn rồi chảy về đây.

*This repository syncs ONE WAY from https://nhatnguyet.org. A pull request editing files
under `data/` will be overwritten by the next sync, so please do not spend
the effort. If a number looks wrong, open an issue: the fix happens upstream
and flows back here.*
